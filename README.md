# Bharat Metal & Tubes — Website

Static website for **Bharat Metal & Tubes**, Bhanpuri, Raipur (Chhattisgarh) —
stockist & supplier of ferrous & non-ferrous industrial metals (stainless steel,
carbon steel, mild steel, pipes, tubes, sheets, plates, flanges, fittings,
valves, IBR & boiler items, Hardox plates, copper, brass & aluminium).

## Tech
Plain static site — HTML, CSS, JavaScript. No build step, no backend.
Enquiry form uses Web3Forms (client-side) with a WhatsApp / Gmail fallback.

## Structure
- `index.html` and page files at the root
- `css/style.css` — all styles
- `js/script.js` — nav, weight calculator, enquiry handling, header parallax
- `images/` — product photos, logo, favicon

## Deploy
Any static host. Connected to Netlify — pushing to the `main` branch
auto-deploys the site.
